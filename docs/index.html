The tools

Four tools.
Everything an agent needs.

youtube_search

Multi-query, multi-language search with transcript highlights and a coverage footer.

  • 1–12 queries, each with its own hl/gl
  • Upload window, duration, min views, Shorts, captions
  • Sort by relevance, views or date
  • Views/day for every result
{ "queries": ["AI productivity workflow",
    { "query": "productividad con IA", "hl": "es", "gl": "ES" }],
  "uploaded": "year", "minViews": 10000 }

youtube_fetch

Batch-read up to 25 videos: exactly the slice you need, plus real frames.

  • Transcript by range, chapter or query passages
  • Real video frames at any timestamp
  • Exact publish date, views, likes, comment count, tags
  • Search, filter and sort comments, with replies
  • Chapters and thumbnail
{ "videos": ["TL8V41Ea6oM", "htZRCE2GgIs"],
  "parts": ["transcript", "frames"],
  "start": 0, "end": 30, "frames": 4 }

youtube_channel

A channel's videos with an outlier score: views divided by the channel's median.

  • Videos, Shorts or streams
  • Latest, popular or oldest, up to 300
  • Subscribers and video count
  • Filter to breakouts with minOutlier
{ "channel": "@aliabdaal", "limit": 60,
  "minOutlier": 2 }

youtube_doctor

Checks every path from your machine, with timings, and says what to do when something fails.

  • Search, details, transcripts, watch page, channels
  • yt-dlp and ffmpeg for frames
  • Shows an active rate-limit pause

Use cases

Ask it like
you'd ask a researcher.

Hook research

Collect the opening lines and first frames of the best videos on a topic, typed by hook pattern.

“List 20 hooks from this year's top AI productivity videos, with hook type and what's on screen.”

Creator breakouts

Find which videos beat a channel's median by 3×, then compare their titles, topics and hooks.

“Which of @channel's videos broke out this year, and what do they have in common?”

What people actually said

Verbatim quotes, claims and advice across many videos, each with the exact second.

“What do creators say is the biggest mistake with AI note-taking? Quote them.”

Multi-language scans

One topic, written natively in every market's language, merged into one de-duplicated list.

“How is ‘vibe coding’ covered in English, German and Spanish YouTube?”

Visual analysis

Frames show the setup, b-roll, on-screen text and pace of cuts: the part transcripts miss.

“How do the top 5 tutorials on Notion AI look in their first 20 seconds?”

Audience questions

Search the comments for a topic, filter by likes, sort by most liked and pull the replies, with a count of how many were scanned.

“Search the comments of these 5 Claude Code tutorials for questions about pricing, most liked first.”

Honest limits

What it can't do
(yet).

Transcripts are rate-limited

YouTube throttles caption downloads per IP. A burst of ~100 in a few minutes triggers a pause. The server stops, says how long to wait and keeps everything else working. For big sweeps, set YT_PROXY.

Search dates are approximate

Search results carry “3 weeks ago”, so date filters are ±1 unit. youtube_fetch returns the exact publish date.

No captions, no transcript

Videos without manual or automatic captions have no transcript. There is no speech-to-text in the server; frames still work.

Comment search covers the top comments

You can search, filter and sort up to 1,000 top comments per video, with replies. YouTube no longer offers anonymous clients the “newest first” sort, so it is not every comment.

Questions.

Does it need a YouTube API key?

No. It talks to the same internal endpoints the YouTube website and apps use, with no API key, OAuth or cookies. yt-dlp and ffmpeg are optional and only needed for video frames.

Which AI clients does it work with?

Any client that speaks the Model Context Protocol. It ships as a Claude Code plugin and a Codex plugin (server plus skill), and runs as a plain stdio server in Claude Desktop, Cursor, Windsurf, VS Code, Zed and others.

What is the research skill?

Instructions the agent loads for YouTube research: define the result first, plan queries in every relevant language, fan out to parallel subagents, then merge, spot-check quotes and report coverage. It includes references for hooks (with a 10-type taxonomy), quotes and claims, creator outliers and the final write-up.

Does it download whole videos?

No. Transcripts come from caption files. For frames, ffmpeg seeks inside the stream with HTTP range requests and decodes only the frames you ask for.

What happens when YouTube rate-limits it?

Caption downloads get their own slower queue. On the first 429 the server pauses transcripts instead of retrying (retries extend the block), tells the agent exactly how many seconds to wait, and keeps search, details, frames and channels working. For very large sweeps, route requests through a proxy with YT_PROXY.

Does it work with non-English videos?

Yes. Each query can carry its own interface language and region, transcripts default to the video's original language, and highlights fold accents and match inflected word forms, so a sweep across several markets lands in one de-duplicated list.

Is it affiliated with YouTube or Google?

No. It is an independent open-source project. Use it in line with YouTube's terms and respect creators' rights when you quote or reuse their content.

Does it cost anything?

No. It is free and open source under the MIT license. The code is on GitHub.
